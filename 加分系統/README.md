# 加分系統

以 Google Apps Script 製作的加分系統網頁應用程式。

- 部署網址（Web App）：https://script.google.com/a/macros/typ.kh.edu.tw/s/AKfycbzF7ecLbSv74o9-1bPuSvOsjjPUO2XeX41w2SdLSapZAkb0OH_glkzmjmZbDpW1PeJSBA/exec

## 修改流程

1. 從 Apps Script 編輯器複製所有檔案（`.gs`、`.html`）到此資料夾，檔名與編輯器中相同。
2. 在此資料夾修改程式碼並 commit 到 GitHub。
3. 將修改後的程式碼貼回 Apps Script 編輯器。
4. 「部署」→「管理部署作業」→ 編輯現有部署 → 版本選「新版本」→ 部署（`/exec` 網址不變）。
