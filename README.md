# TYPencourageset

高雄市桃源國小全校加分系統：老師用學校 Google 帳號在網頁上給分，取代貼在聯絡簿上的紙條。程式跑在 Google Apps Script 上，資料存在 Google 試算表裡。

| 檔案 | 內容 |
|---|---|
| `Code.gs` | 伺服器端：身分判斷、給分、撤回、讀寫試算表 |
| `Index.html` | 整個網頁介面（樣式、畫面、互動都在這一個檔案裡） |
| `使用說明.md` | 安裝、部署和日常使用的說明 |
| `PRODUCT.md` | 設計方向：使用者、限制、配色 |

## 在不同電腦上修改

GitHub 上的檔案只是**備份和版本紀錄**，真正在跑的程式在 Apps Script 專案裡。改完後兩邊都要更新：

1. 改好 `Code.gs` 或 `Index.html`，推上 GitHub。
2. 把同一份內容貼進 Apps Script 編輯器，存檔。
3. **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**。網址不會變。
